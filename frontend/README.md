# Frontend (React + Vite)

Pasta frontend contém uma aplicação React mínima que consome a API Flask.

Como rodar:

1. Entre na pasta frontend:
   cd frontend

2. Instale dependências:
   npm install

3. Rode em modo dev:
   npm run dev

A aplicação será carregada em http://localhost:5173 e a API em http://localhost:5000
